¡Bienvenido al repositorio **Java Clases**! 🚀 Aquí encontrarás una extensa colección de ejercicios y proyectos desarrollados en Java, diseñados para aprender y practicar desde conceptos básicos hasta estructuras de datos complejas y simulaciones.

---

## 📂 Estructura del Proyecto

### 📝 Ejercicios Básicos y Lógica
Una serie de ejercicios fundamentales (`Ejercicio1.java` a `Ejercicio19.java`) que cubren:
- **Entrada/Salida de datos** (`Scanner`)
- **Conversiones** (Binario, Tiempo, Velocidad)
- **Matemáticas y Lógica** (Cuadrados, Perímetros, Divisibilidad, Números Primos)
- **Estructuras Condicionales** (`if`, `switch`)
- **Arreglos y Matrices** (Unidimensionales, Bidimensionales y Ordenamiento)

### 🔄 Ciclos y Repeticiones (`Ciclos/`)
Ejercicios enfocados en el uso de bucles (`for`, `while`, `do-while`):
- ✖️ Tablas de multiplicar.
- 📐 Patrones visuales (triángulos de asteriscos).
- 🔐 Menús interactivos y validación de intentos.

### 📚 Tareas y Prácticas Específicas
- **`Tarea/`**: Prácticas con arreglos y múltiplos.
- **`Array/`**: Manipulación avanzada de arreglos (Nuevos ejercicios).
- **`clase__de_hoy/`**: Manipulación de **Strings** (Inversión de frases, conteo de caracteres).
- **`intercambios/`**: Algoritmos de intercambio de elementos usando `ArrayList` (ej. intercambio de láminas y actualizaciones).
- **`matriz/`**: Operaciones matemáticas avanzadas como la multiplicación de matrices sucesivas.

### ⚽ Proyectos Destacados
- **`Mundial/` & `Proyecto Mundial/`**: Simulador completo de un Mundial de Fútbol. Desde el sorteo de grupos, registro de marcadores, hasta el avance de fases, utilizando matrices bidimensionales y estructuras de datos.

---

## 🛠️ Tecnologías Utilizadas

* **Lenguaje:** Java ☕
* **Estructuras:** Arrays, Matrices, ArrayLists, Strings.
* **Control de Flujo:** if/else, switch, for, while, do-while.
